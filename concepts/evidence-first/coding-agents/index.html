What an agent can use

Evidence is more useful when it is addressable.

Current

MCP and structured recovery

The public MCP surface can expose task-oriented tools, evidence references, and structured error.hint fields for agent recovery.

Current

Browser evidence

Screenshots, trace context, observed outcomes, and exportable Playwright artifacts give a person or agent something concrete to inspect.

Limited

Packaged command distribution

The cohesive molar verify, molar agent init, and molar docs journey is a limited distribution surface while packaging is completed.

Agent boundary

Autonomy stays inside explicit authority.

Read and observe · Current An agent can consume the result and follow references to browser evidence exposed by the configured surface.

Retry and re-verify · Limited Automated fix-and-verify loops depend on the caller, environment, and available task interface.

Destructive actions · Deployment-dependent Purchases, deletes, permission changes, and other high-risk actions require configured policy and, where appropriate, human approval.
