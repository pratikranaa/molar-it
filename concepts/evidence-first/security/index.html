Molar · security boundaries

Verification within explicit boundaries.

A browser agent should know what it may observe, which actions require approval, where evidence is stored, and what remains specific to a deployment.

Boundary map

Authority is part of the verification result.

Security posture · qualified by deployment

Current

Observe with context

Runs can preserve browser actions and evidence context while configured controls constrain the available surface.

Limited

Apply scoped controls

Credential, redaction, and retention mechanisms vary across services and must be evaluated against the chosen run path.

Deployment-dependent

Match the environment

Private connectivity, enterprise identity, custom retention, and approval policy depend on the supported deployment.

Credentials and actions

Possession of a credential is not permission to do everything.

Credentials · Current Configured run paths can use scoped project credentials and synthetic identities. Secret handling must be reviewed for the service and deployment actually in use.

Action approval · Limited Workflows can distinguish observation from mutation, but the exact approval mechanism is not uniform across every surface.

High-risk actions · Deployment-dependent Purchases, destructive changes, broad permission grants, and production mutations require explicit policy and may require human approval.

Isolation

Keep browser state and organizational context bounded.

Current

Session boundaries

Browser sessions can isolate persona cookies, account state, and device context for a bounded run.

Limited

Tenant scoping

Workspace-scoped control-plane paths exist, but exact Tenant isolation guarantees must be confirmed for each deployed service and legacy surface.

Deployment-dependent

Network boundary

Private application access, egress policy, proxy routing, and regional requirements depend on the selected environment.

Evidence lifecycle

Retain what is useful. Expose what needs review.

Audit · Current Trace and run evidence can record what the agent observed, what action it chose, and which outcome was verified.

Redaction · Limited Available filtering and evidence controls depend on the artifact type and configured storage path; sensitive fixtures still require deliberate setup.

Retention · Deployment-dependent Duration, deletion workflow, storage location, and custom retention policy vary by plan, service, and supported deployment.

Evaluation note

This concept describes product and deployment boundaries, not an external certification status. Confirm the controls required by your organization during security review.
