Usage definitions

A verified run has a boundary.

Verified run One bounded execution of a goal or scenario against a declared application environment, with an adjudicated result and its available evidence.

Variable cost Agent compute, browser time, proxy use, evidence retention, and controlled integration state can have different cost characteristics.

No invented overages These plans do not imply unlimited agent compute. Capacity or overages not listed here require a conversation rather than an invented rate.

Maturity still applies A plan allocation does not override Current, Limited, Proposed, or deployment-dependent capability boundaries.
