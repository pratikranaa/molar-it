# Self-hosted Instant Proof fonts

Vendored for `molar.it/verify` so Instant Proof does not call Google Fonts
(privacy / CSP / offline). Latin + latin-ext variable WOFF2 subsets.

| Family | Weights used | License | Upstream |
|--------|--------------|---------|----------|
| Bricolage Grotesque | 500–600 | SIL OFL 1.1 — `OFL-Bricolage-Grotesque.txt` | [ateliertriay/bricolage](https://github.com/ateliertriay/bricolage) |
| Instrument Sans | 400–600 | SIL OFL 1.1 — `OFL-Instrument-Sans.txt` | [Instrument/instrument-sans](https://github.com/Instrument/instrument-sans) |
| Geist Mono | 400–500 | SIL OFL 1.1 — `OFL-Geist.txt` | [vercel/geist-font](https://github.com/vercel/geist-font) |

OFL allows bundling and redistribution with software; do not sell the fonts alone.
Keep the reserved font names and ship the OFL text alongside the binaries.
