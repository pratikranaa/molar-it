Core service clones

These five clones cover the integration paths teams most often need to test: payments, email, SMS, identity, and object storage.

Auth (Clerk) clone — Test Clerk-style auth flows against a stateful auth clone — sessions, users, and org membership without real identities.

S3 clone — Test upload and asset flows against an S3 shadow mirror — same SDK calls, no real bucket writes.

SendGrid clone — Test transactional email flows against a stateful SendGrid clone — capture messages without delivering to real inboxes.

Stripe clone — Test billing and checkout agents against a stateful Stripe clone with real error shapes — no test-mode gaps, no real charges.

Twilio clone — Test SMS and voice workflows against a stateful Twilio clone with real REST error shapes.

Supplementary fixture coverage

Additional vendor shaped fixtures support focused agent and integration workflows. Each page identifies its status and the routes it covers.

Apify clone — Test Apify scraping agents against a stateful clone of actors, runs, datasets, key-value stores, and request queues with real REST error shapes.

Cal.com clone — Test scheduling flows against a Cal.com launch-preview clone — bookings, availability, and calendar hooks without real calendar writes.

Clickup clone — Test task automation against a ClickUp clone — lists, tasks, and status changes with ClickUp REST semantics.

Discord clone — Test Discord bot flows against a stateful Discord API clone — guilds, channels, and messages without touching production servers.

Firecrawl clone — Test web-scrape agents against a Firecrawl launch-preview clone — crawl jobs and extracted content without hitting the live API quota.

Github clone — Test GitHub agents against a stateful clone of repos, files, branches, issues, PRs, commits, and workflow runs with real GitHub API error shapes.

Gitlab clone — Test GitLab CI and repo agents against a GitLab API clone — projects, merge requests, and pipelines without touching real remotes.

Google Workspace clone — Test Google Workspace automations against a launch-preview clone — Gmail, Calendar, and Drive-shaped APIs in isolated sessions.

Hubspot clone — Test CRM and marketing automations against a HubSpot architecture-preview clone — contacts, deals, and pipeline state in isolation.

Jira clone — Test Jira automation agents against a stateful Atlassian clone — issues, transitions, and sprint fields with Jira REST error shapes.

Linear clone — Test issue-tracking agents against a stateful Linear clone — issues, cycles, labels, and team workflows with REST-shaped errors.

OwnerRez clone — Test vacation-rental ops against an OwnerRez architecture-preview clone — bookings, guests, and property state.

PriceLabs clone — Test dynamic-pricing integrations against a PriceLabs architecture-preview clone — listings and rate recommendations.

Ramp clone — Test spend and card workflows against a Ramp architecture-preview clone — transactions and limits without real money movement.

Sentry clone — Test Sentry triage agents against a stateful clone of organizations, projects, issues, latest events, stack traces, and releases with real REST errors.

Slack clone — Test Slack bots and workflow automations against a stateful Slack API clone — channels, messages, and reactions without posting to real workspaces.

Supabase clone — Test Supabase management workflows against a fixture clone — projects, branches, secrets, and migrations without a live project.

Tavily clone — Test research agents against a Tavily architecture-preview clone — search queries and citations without live search quota.

Telegram clone — Test Telegram bot flows against a Bot API clone — messages, updates, and chat state without contacting real users.

Typeform clone — Test form and survey agents against a Typeform clone — forms, responses, and webhooks without production form traffic.

Unipile clone — Test unified inbox agents against a Unipile architecture-preview clone — email, calendar, and messaging APIs in one session.

Webflow clone — Test Webflow content agents against an Architecture Preview with recording-backed Data API v2 routes and focused CMS overlays.

Woocommerce clone — Test WooCommerce store flows against a REST clone — orders, products, and customers without a live WordPress store.
