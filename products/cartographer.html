Give the exploration a useful boundary.

Choose a starting page, the account role, and the part of the app you want to understand. The map reflects what the run observed within those limits.

  1. Start with the right environment

    Use a preview or test app for flows that create accounts, submit forms, or change data. Connect its test services before exploring payment or messaging paths.

  2. Choose the account’s point of view

    A saved member profile and an admin profile reveal different routes. Profiles must belong to the same project and website as the exploration.

  3. Set the area and size of the map

    Limit allowed hosts, link depth, total pages, and repeated URL patterns. State a focus such as signup and settings so the run has a useful starting point.

  4. Read the limits with the results

    Check which pages and transitions were observed, where access was missing, and whether a limit stopped discovery. An unexplored route is not a passing check.

answered.

Have a specific workflow in mind?
Let’s talk it through

What should I give Cartographer first?

Give it an authorized URL and one concrete goal, such as reaching a dashboard after email verification or showing an order receipt after checkout.

Can Cartographer run against localhost?

Yes. Local browser verification is a supported path. Hosted runs use the target and credentials you configure.

What does the route map represent?

It represents pages and transitions observed during an exploration or task. Select a route to inspect its browser actions, expected result, and illustrative assertion.

Can I use a logged-in test account?

Use an authorized saved profile or credential reference for the application. Saved sign-in state stays tied to the website it belongs to.

What is the difference between molar run and molar verify?

molar run starts a goal-directed browser task and may change state. molar verify checks a claim against a URL or prior task result and is intended for read-only verification.

Can I keep my Playwright suite?

Yes. Keep existing Playwright tests alongside Cartographer checks. Generated export and clean replay are being validated in beta for the environments that support them.

Does reaching a page mean the flow passed?

No. A discovered page or a completed click is not an assertion. Check that the requested result was observed, and review blocked or unvisited branches separately.

Can I record a flow with the browser extension?

Recording support is being developed and validated in beta. Ask the team about your browser and authentication setup; it is not yet offered as a universal self-serve record-and-replay workflow.

What happens when access or setup blocks a run?

The run can return a blocked status with the available task, Trace, screenshot, and artifact references. Review the missing access or input before trying again.
