Let’s talk it through

What does Guard run?

Guard runs configured scenarios in CI or on a schedule, including browser journeys that use supported Clones for payment, identity, email, SMS, or storage behavior.

Does Guard block every merge automatically?

It can be wired as a required check once your repository connection and scenario policy are set up; it does not create a policy for every repository by default.

Can Guard monitor production?

Guard supports scheduled checks for authorized live URLs. Availability depends on the environment and current beta workflow.

What does a failed check show?

The result keeps the scenario and run identity with the failing assertion and available Trace, screenshot, and artifact references for investigation.

Does Guard replace my Playwright tests?

No. Guard can run supported Playwright-based checks alongside your existing suite. Cartographer-generated export and clean replay are being tested in beta.

Can Guard repair a failure?

Mender is a separate preview workflow that prepares a proposed repair for review. It does not apply an unapproved change automatically.
