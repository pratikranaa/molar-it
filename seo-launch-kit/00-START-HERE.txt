Run these after deploying the apex site to Cloudflare Pages.

1. google-search-console.txt — verify domain, submit sitemap, request indexing (incl. surface subdomains)
2. keyword-map.txt — per-surface competitors, target queries, GSC monitoring list
2. bing-webmaster.txt — Bing + Copilot
