Let’s talk it through

What can Molar do in a browser?

Find and download files, fill forms, read information from pages, explore an app and check that a task reached its expected result.

Can my coding agent use it?

Yes. Connect through the CLI or MCP to start browser tasks and inspect the result.

Can I watch what happens?

Molar brings browser steps and run evidence together so you can follow the task and investigate where it stopped.

Can I keep using Playwright?

Yes. Molar works alongside Playwright workflows. Read the quickstart to choose the right starting point for your project.

How do I start?

Create an account and add the app you want to work with. Molar is in beta; our team can help set up your first workflow.

you’d hand over?
