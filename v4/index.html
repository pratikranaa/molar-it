FAQ

Frequently asked questions

Straight answers about what Molar is — and what this v4 page is for.

What is Molar?

Molar is a universal browser-automation and verification platform: Cartographer (explore/export), Guard (PR + prod), Clones (hermetic vendors), Trace (replay/debug), plus Plumbing (control plane, MCP, CLI, dashboard).

How is this different from Playwright alone?

Playwright is the execution substrate agents and LLMs know best. Molar adds agentic exploration, scenario authoring, hermetic clones, PR gating, livestream, Trace evidence, and MCP/CLI so coding agents can verify changes without a human in the loop.

Can coding agents use Molar directly?

Yes. MCP tools and the molar CLI return structured output (including --json). Agents can call verify/run/live-view flows and self-correct from evidence.

Will Instant Proof charge real cards or email real users?

No. Clones and production-safety preflight exist so tests stay off live vendor rails. Instant Proof is the public stranger path to see a real browser verification before deeper setup.

What is this /v4/ page?

An isolated future marketing layout. Production molar.it root remains the live homepage until an explicit cutover. This page is noindex and versioned for iteration.

Where are docs?

Product docs: docs.molar.it. Quickstart marketing docs also live under molar.it/docs. Surface landings: cartographer / guard / clones / trace.molar.it.
